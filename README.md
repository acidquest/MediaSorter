# MediaSorter

Нативное приложение Windows на WinUI 3 для сортировки фото и видео по датам. C# / .NET 10, Windows App SDK 1.8. Переносимая сборка x64: Windows 10 2004+ / Windows 11.

## Запуск

После сборки запустите `artifacts/MediaSorter/MediaSorter.exe`. Для переноса на другой компьютер копируйте **всю папку**, не только EXE. .NET, WinUI и библиотека чтения метаданных включены в сборку. Установщик не требуется.

Для разработки: Visual Studio 2026, .NET 10 SDK и Windows SDK 26100. Открыть `MediaSorter/MediaSorter.csproj`. Сборка и тесты из PowerShell:

```powershell
.\build.ps1
```

## Работа

1. Выберите исходную папку слева сверху. По умолчанию назначение — `исходная папка\out`; его можно изменить слева снизу.
2. Выберите шаблон, типы файлов и глубину обхода. Выходная папка исключается из рекурсивного обхода.
3. «Разложить по папкам» сначала показывает наглядный план: сводку количества и размера, будущие папки слева и их содержимое справа. Конфликты имён и недоступные файлы отмечены отдельно. Перемещение начинается только после подтверждения.
4. Выделите файл для просмотра и откройте вкладку «О файле» для метаданных. Выделение папки показывает миниатюры; двойной клик открывает папку в списке.
5. В медиатеке используйте Ctrl/Shift для выделения, F2 для переименования, Delete для корзины, Ctrl+M для объединения, Backspace для перехода вверх, F5 для обновления. Действия также доступны снизу и через контекстное меню.

В исходных файлах также доступно удаление в корзину: кнопка снизу, контекстное меню и Delete. Можно выделить несколько файлов. Перед удалением отображается подтверждение.

Внизу медиатеки слева показано количество папок и/или файлов, справа — кнопки управления. Удалённые элементы убираются из текущего списка без повторного обхода каталога; положение прокрутки сохраняется (в конце списка ограничивается новой высотой содержимого).

В просмотрщике есть кнопки перехода к первому, предыдущему, следующему и последнему файлу с индикатором позиции. Навигация следует списку, из которого выбран файл, или содержимому открытой галереи. На границах списка соответствующие кнопки отключаются.

Колесо мыши над открытым фото или видео перелистывает файлы: вниз — следующий, вверх — предыдущий. В галерее колесо продолжает прокручивать миниатюры. Быстрая прокрутка ограничена, чтобы не запускать одновременно несколько загрузок видео.

Перетащите заголовок панели на другой заголовок или используйте меню заголовка для перестановки. Вертикальный разделитель меняет ширину колонок, горизонтальные разделители слева и справа независимы. Центральная точка меняет обе оси сразу. Минимальная ширина колонки — 120 DIP, высота панели — 80 DIP. Раскладка сохраняется.

## Шаблоны и даты

- `yyyy\MM-dd` → `2026\04-28`.
- `yyyy\dd.MM.yy` → `2026\28.04.26`.
- `yy-mm-dd` → `26-04-28` (`mm` означает месяц).
- `'Отпуск'\yyyy\MM-dd` → `Отпуск\2026\04-28`.
- Текст в одинарных кавычках сохраняется буквально; разделители `/` и `\` создают уровни каталогов.
- Windows не разрешает имена с точкой в конце: `MM-dd.` выдаст понятную ошибку, а не незаметно изменится.

Приоритет: EXIF Original → EXIF creation/modification или встроенная дата создания → Windows DateTaken/DateEncoded → время изменения файла → время создания файла. Дата EXIF без часового пояса сохраняет локальное время съёмки; UTC-даты переводятся в локальный часовой пояс. Источник выбранной даты виден в плане и метаданных. Время изменения стоит перед файловым временем создания, поскольку копирование с устройства часто сбрасывает именно время создания.

Объединение собирает содержимое выбранных папок, включая вложенные файлы, в одну папку текущего каталога. Имя предлагается по фактическому диапазону дат и активному шаблону; его можно исправить. Пустые исходные папки удаляются только после успешного переноса всех файлов.

## Безопасность

- Совпадающие имена получают `(2)`, `(3)` и т.д. Перезапись запрещена, в том числе при появлении нового файла после построения плана.
- Перед каждым переносом проверяются размер и время изменения исходника.
- На одном томе — обычное перемещение; между томами — временная копия, SHA-256, переименование копии, удаление исходника. При ошибке удаления исходника может остаться проверенная копия; ошибка отображается.
- Символические ссылки и junctions не обрабатываются.
- Отмена сохраняет уже завершённые перемещения. Автоматического отката нет.
- Журнал JSONL хранится в `%LOCALAPPDATA%\MediaSorter\logs`: намерение перед переносом, результат после него. Журнал помогает разобраться в частичном выполнении, но не является системой резервного копирования.
- Удаление выполняется через корзину Windows после подтверждения.

## Ручное перемещение в медиатеке

- Выберите файлы (Ctrl/Shift), нажмите «Вырезать» или Ctrl+X, откройте папку назначения и нажмите «Вставить» или Ctrl+V. Можно также выделить одну папку назначения и вставить прямо в неё. До подтверждения плана файлы остаются на месте.
- «В Разное» перемещает выбранные медиафайлы или медиа из выбранных папок, включая вложенные, в `Разное` в корне выходного каталога. Без выделения обрабатывается текущая папка с подпапками. Папка создаётся автоматически; сама `Разное` исключается из обхода. Оригиналы после успешного переноса не сохраняются. Полностью перенесённые исходные папки, содержащие лишь пустые подпапки, удаляются в корзину. При оставшихся файлах, ошибках или незавершённом переносе папки сохраняются.
- Если подписи кнопок медиатеки не помещаются, остаются только иконки с подсказками; при расширении панели подписи возвращаются.
- Одноимённые файлы получают числовой суффикс без перезаписи. Для ручных переносов действуют проверка исходника, журнал и проверка копии при переносе между томами.
- Переименование и удаление не сбрасывают прокрутку. «Выше» выделяет папку, из которой вы вышли. В диалоге переименования начальный фокус — на «Продолжить».

## Локализация и просмотр

Русский и английский; по умолчанию язык и тема системы. Настройки и раскладка хранятся в `%LOCALAPPDATA%\MediaSorter\settings.json`. Новый язык: добавьте `Locales/<код>.json` рядом с EXE, используя ключи `en.json`, и перезапустите приложение. Пропущенные переводы берутся из английского файла.

Метаданные читаются локально библиотекой MetadataExtractor и Windows Shell. Просмотр использует декодеры Windows. При отсутствии поддержки HEIC/HEVC/RAW или другого формата приложение сообщает об этом и предлагает открыть Microsoft Store для установки расширения либо открыть файл во внешнем приложении. Установка платных/системных кодеков требует участия пользователя; приложение не скачивает произвольные кодеки из интернета. Отсутствие декодера не мешает сортировать файл по доступной дате.

Фото и видео автоматически вписываются в область просмотра с сохранением пропорций, в том числе при изменении её размера. Видео: стандартные элементы воспроизведения. Галерея показывает до 300 миниатюр из выбранной папки; полный список файлов доступен в медиатеке. Списки виртуализированы, дисковые операции и чтение метаданных выполняются вне UI-потока.

Сводка файла показывает дату и её источник, формат, размер, разрешение, длительность видео, камеру и основные параметры съёмки при наличии. Служебные EXIF-поля не выводятся. Заголовок окна и системные кнопки следуют выбранной теме. Иконка приложения — собственный векторный дизайн `MediaSorter/Assets/app.svg`; PNG и многоразмерный ICO воспроизводимо генерируются проектом `tools/IconGenerator`.

## Проверки

`dotnet run --project Sorter.Tests` проверяет шаблоны, защиту путей, фильтры, исключение output, конфликты имён, изменение источника, отмену, журнал, обычный перенос и ветку копирования с SHA-256. Проверки создают только собственные временные файлы.

`dotnet run --project Sorter.MetadataTests` проверяет настоящую EXIF-дату в созданном JPEG, fallback для видео без метаданных и интеграцию с планом сортировки.

Регрессионная проверка просмотрщика на собственных JPEG/H.264-фикстурах:

```powershell
dotnet run --project Sorter.MetadataTests -- --fixtures C:\dev\sorter\.build\fixtures
.\artifacts\MediaSorter\MediaSorter.exe --smoke-test=C:\dev\sorter\.build\fixtures
```

Результат — `.build/fixtures/ui-smoke-result.json`. Проверяются загрузка четырёх панелей, вписывание фото, изменение размеров, четыре переключения воспроизводимого видео на фото, темы кнопок заголовка, сводка метаданных и галерея. Пути в примере замените на каталог вашего клона. Обычный запуск не включает тестовый режим.

Проверено: Release-сборка, 30 проверок ядра, 3 интеграционные проверки метаданных, 51 проверка интерфейса (включая адаптивные кнопки, безопасную очистку папок после переноса, прокрутку после переименования и удаления, возврат к папке, фокус подтверждения и вписывание миниатюр). Внешняя визуальная автоматизация в текущей среде недоступна; ручная проверка компоновки на разных DPI и редких видеокодеков остаётся необходимой.

Реальные медиатеки сначала проверяйте через план сортировки. Приложение не меняет содержимое метаданных и не удаляет дубликаты по содержимому.
